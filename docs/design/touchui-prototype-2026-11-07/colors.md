# TopFlow 触屏控制中心 · 颜色表

适用于 320 × 480 竖屏叠层触屏。默认夜间；点按九宫格「主题」格切换日间/夜间。颜色以 CSS 自定义属性写在 `index.html` 的 `.screen` 作用域内，主题切换只替换变量，不改结构。落地到设备时，将同一组值写入 `/data/touchscreen-control-center/` 的配色配置。

## 对比度校验（WCAG AA）

正文与次要文字均按 4.5:1 以上校验；数值为前景/背景的实际对比度。

| 组合 | 夜间 | 日间 |
| --- | --- | --- |
| 正文 / 背景 | 18.31 | 15.93 |
| 正文 / 卡片 | 16.57 | 17.75 |
| 次要文字 / 背景 | 8.22 | 5.72 |
| 次要文字 / 卡片 | 7.44 | 6.38 |
| 强调色 / 卡片 | 10.70 | 5.84 |
| 强调色上的文字 / 强调色 | 10.12 | 5.84 |
| 正常 / 卡片 | 10.36 | 6.25 |
| 警告 / 卡片 | 11.09 | 6.79 |
| 错误 / 卡片 | 7.16 | 6.23 |
| 正常 / 浅底 | 8.97 | 5.44 |
| 警告 / 浅底 | 9.58 | 5.80 |
| 错误 / 浅底 | 6.84 | 5.10 |

结论：两套主题全部通过 AA；夜间正文、强调色、状态色在卡片上均达到 AAA（≥7:1）；日间强调色与状态色达到 AA（≥4.5:1），正文仍达 AAA。

## 使用约束

- 强调色只用于「可操作/正在生效/正在充电」；正常运行状态用正常色，弱信号用警告色，停止/失败用错误色，避免同一屏出现两种以上状态色抢占注意力。
- 状态色不做大面积实底；需要底色时使用对应的 `*-soft`，文字仍用状态色。
- 卡片与背景靠 1px 边框和明度差分层，不用玻璃拟态、模糊叠层或渐变。
- 日间主题下，强调色实底按钮文字使用 `--accent-ink`；夜间同理，保证 10:1 以上。
- 九宫格禁用格使用 `--card-2` + 虚线边框 + 次要文字；空位使用透明底 + 虚线边框，二者不可点击。
